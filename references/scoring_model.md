# 五维评分模型 · 完整口径

本文档回答一个问题：**每一个数字是从哪来的。**
凡是「原看板披露」和「我按实测分布设定」的，分开标注，不混着写。

### 量能 25 / 题材 10 怎么反推的

原看板展示了五维平均分：

> 主力资金净流入 23.2 · 龙虎榜机构/游资 5.3 · 量能特征 13.9 · 题材级别 9.4 · 均线与K线形态 8.4

已知资金 30、龙虎 25、形态 10 三个权重，总和 65，剩余 35 分配给量能与题材。
按「量能 > 题材」的常规设计（量能可量化、题材偏主观），取 25 / 10。
校验：13.9/25 = 55.6%，9.4/10 = 94%，量能占 55.6% 属合理中位，
题材占 94% 说明原模型该维度几乎无区分度（见 §5）。

## 2. 档位阈值与分位锚点

**全部阈值由我设定**（原看板未公开），锚定 2026-11-02 涨停池 125 只的实测分位：

| 指标 | P10 | P25 | P50 | P75 | P90 | P95 |
|---|---|---|---|---|---|---|
| 主力净流入 | 0.13亿 | 0.22亿 | 0.47亿 | 0.91亿 | 1.90亿 | 3.06亿 |
| 换手率 | 1.89% | 3.42% | 6.62% | 10.97% | 17.30% | 20.28% |
| 量比(额) | 0.68× | 0.87× | 1.39× | 1.97× | 3.12× | 3.72× |
| 封单/流通市值 | 0.09% | 0.19% | 0.56% | 1.26% | 2.07% | 3.30% |

设计原则：**中位票拿该维度的 ~65-70%，P90 以上接近满分，只有头部个股能进 S 级。**

### 2.1 资金（满分 30）

| 当日主力净流入 | 基础分 |
|---|---|
| ≥ 3.0 亿 | 29.0 |
| ≥ 2.0 亿 | 27.5 |
| ≥ 1.2 亿 | 25.5 |
| ≥ 0.9 亿 | 24.5 |
| ≥ 0.6 亿 | 22.0 |
| ≥ 0.47 亿 | 20.0 |
| ≥ 0.3 亿 | 17.0 |
| ≥ 0.13 亿 | 13.5 |
| ≥ 0 | 9.0 |
| < 0（净流出） | 3.0 |

修正项：占流通市值 ≥4% +1.5 / ≥2% +1.0 / ≥1% +0.6；
近5日累计净流入 > 当日 **+1.0**；近5日累计为负 **−3.0**。上限 30。

### 2.2 龙虎榜（满分 25）

- **未上榜：4.0 基线**（占权重 16%）——理由见 §5.2
- 上榜次数（按上榜原因去重）：1 次 10.0 / 2 次 15.0 / ≥3 次 18.0
- 席位净买入：≥2亿 +7.0 / ≥1亿 +5.5 / ≥0.5亿 +4.0 / >0 +2.0 / 净卖出 −2.0
- 买方席位含「机构专用」+2.5

### 2.3 量能（满分 25）

| 换手率 | 分 | 量比(当日额/前5日均额) | 分 | 封单/流通市值 | 分 |
|---|---|---|---|---|---|
| 4-25% | 9.0 | ≥2.5× | 8.5 | ≥3% | 5.0 |
| 2-4% 或 25-35% | 7.0 | ≥1.8× | 7.2 | ≥1.5% | 4.2 |
| 1-2% 或 35-50% | 5.0 | ≥1.2× | 5.8 | ≥0.8% | 3.2 |
| <1% 或 >50% | 3.5 | ≥0.9× | 4.2 | ≥0.3% | 2.2 |
| — | — | <0.9× | 2.8 | <0.3% | 1.2 |
| — | — | 历史不足 | 4.8 | — | — |

首封时间：≤10:00 +2.5 / ≤11:00 +1.9 / ≤14:00 +1.4 / 尾盘 +0.9。
炸板惩罚：每次 −1.0，最多 −3.0。上限 25。

> 换手区间取 4-25% 为满分，是因为 2026-11-02 当日 Top1（襄阳轴承，换手 33.2%）
> 与多只强票都落在 25-35%。妖股的「充分换手」是特征而非缺陷，只有 >50% 才算过热。

### 2.4 题材（满分 10）

行业当日涨停家数：≥6 家 7.0 / 4-5 家 6.5 / 3 家 6.0 / 2 家 5.5 / 1 家 5.0。
所属行业进入当日涨停家数 Top3 +1.8。连板 ≥3 +1.2 / 2 板 +0.6。上限 10。

### 2.5 形态（满分 10）

- 突破 60 日收盘新高 4.2（基础分起点 2.0）；突破 20 日新高 3.4；否则 2.0
- 均线：ma5>ma10>ma20 +3.0；收盘>ma5 且 >ma10 +2.2；仅>ma5 +1.5
- 放量突破（量比≥1.5 且收盘>ma20）+2.0
- 强势（≥2板 且 5日涨幅≥25%）+0.8

不足 25 根日线（次新股）→ 固定 3.0 并在 `warnings` 留痕，不假装形态成立。

## 3. 总分与分级

总分 = 五维之和（每维先四舍五入到 1 位）。任维度缺失时按可得维度归一化到 100，
并在 `warnings` 标注「部分维度缺失」——**绝不 fallback 成中间分**。

| 区间 | 级别 | 标签 |
|---|---|---|
| ≥80 | S | 妖股候选 |
| 70-79.9 | A | 强关注 |
| 60-69.9 | B | 潜力区间 |
| <60 | C | 观察 |

80 / 60 两级来自原看板，70 是我插入的中间档（原看板只有 3 档，颗粒度太粗）。

## 4. 校准记录（做了什么、为什么）

**v1（首版档位）**：2026-11-02 实测均值 38.3、中位 38.0、≥80 零只、≥70 仅 2 只。
分布整体塌在 30-45 区间，实际是「档位过严导致所有票都像垃圾」，看板失去排序价值。

**诊断**：五维均值 13.2/30、2.9/25、13.6/25、4.6/10、4.0/10，
对照原看板 23.2/5.3/13.9/9.4/8.4 —— 资金与形态两维差得最多。

**v2（按分位重锚 + 修换手逻辑）**：均值 52.7、中位 51.3、S 1 只 / A 9 只 / B 11 只。
60 分以上 21 只（原看板同日为 19 只），分布形态基本对齐。

**没有为了对齐而编数**：v2 均值 52.7 vs 原看板 60.2，差的 7.5 分集中在龙虎榜
（原看板给未上榜票也分了约 5 分，我只给 4 分基线且 31/125 的上榜率导致均值更低）
与题材（原看板 94% 近乎全员满分，我保留区分度）。这两处差异是**有意的**，理由见 §5。

## 5. 与原看板的三处有意分歧

### 5.1 题材维度：原看板 9.4/10（94%），本实现约 6.5/10

94% 的维度均值意味着这个维度几乎不区分任何股票，等于把 10 分权重变成常数项。
本实现按「行业涨停家数 + 是否主线 + 连板高度」给 5.0-10.0，保留排序能力。
代价是总分整体下移约 3 分。

### 5.2 龙虎榜未上榜：给 4.0 而不是 0

125 只涨停股里只有 31 只上龙虎榜。若未上榜给 0，这一维对 75% 的样本完全无差别，
25 分权重白扔；给 4.0 基线（16%）表达的是「无榜 = 未被异动监控」，既非利好也非利空。

**这是主观判断，不是数据结论。** 若你的交易框架认为「没上龙虎榜 = 资金不认可」，
把 `engine.score_lhb` 的 `return 4.0` 改成 `return 0.0`，其余无需改动。

### 5.3 不展示「样本提升倍数 / 命中率」

原看板有「模型样本提升倍数 9.02× · 样本命中 90.5% vs 市场 10%」。
本技能**不生成这类数字**——它需要历史样本回测支撑，而我没有做，也不想编一个
看起来专业的倍数。目前看板给出的只是同池内相对排序，以及每只票的五维拆解与
命中理由，读者可以自己判断排序是否合理。

想补回测：用 `--date` 逐日跑出快照，再用次日/次5日涨幅对分段做胜率统计。
注意届时必须区分「区分度」与「收益率」——排序能把票分开，不等于头部组能赚钱。
